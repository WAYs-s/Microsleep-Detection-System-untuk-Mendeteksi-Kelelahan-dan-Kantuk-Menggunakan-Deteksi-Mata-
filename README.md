## 📘 Deskripsi Proyek  
**Microbreak Detection** adalah aplikasi berbasis Python dan OpenCV yang mendeteksi mengantuk tidaknya seseorang dengan menghitung tingkat keterbukaan mata (Eye Aspect Ratio / EAR) melalui MediaPipe Face Mesh , dan memberikan peringatan otomatis ketika pengguna terdeteksi mengantuk atau kehilangan fokus dalam waktu tertentu.

---

## 🎯 Tujuan Proyek
Membantu pengguna, terutama yang bekerja lama di depan layar, untuk mencegah mengantuk atau kelelahan yang tidak disadari.

---

## ⚙️ Fitur Utama  
1️⃣ Deteksi mata tertutup menggunakan MediaPipe Face Mesh secara realtime
2️⃣ Peringatan otomatis (pop-up dan bunyi alarm) saat mata tertutup melebihi ambang waktu
3️⃣ Dua mode penggunaan:
    Mode User → langsung digunakan tanpa pengaturan teknis
    Mode Developer → Memodifikasi pengaturan threshold EAR, timeout, dan confidence
